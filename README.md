## Overview

Classic Layout draws the whole Termix app: the icon rail, the host and credential sidebar, the tab bar, the right dock, the Dashboard, Manage, Settings and the command palette. It ships with Termix and is the default layout. You can switch to another layout in Settings, Appearance, but not remove it.

Read the [docs](https://docs.termix.site/plugins/classic-layout) to learn how it works.

<br />

## Features

- Icon rail with a resizable sidebar and a right dock
- Tab bar with split view
- A dashboard of tiles you can move and resize, saved with your account
- Manage and Settings screens
- Host and credential lists, and the host editor
- Pick what a click on a host opens, and which buttons show on its row
- Host tools can open inside the Operations Center host page
- Command palette
- Mobile bottom bar

## Support

Bugs and ideas for Classic Layout go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Classic-Layout/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Classic-Layout/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
